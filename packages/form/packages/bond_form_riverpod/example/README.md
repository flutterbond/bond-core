# Bond Form Example

A login form, a pizza order form and a two-step profile stepper built with
`bond_form_riverpod` on Riverpod 3 (`NotifierProvider.autoDispose`),
`material_ui` and `go_router`.

The app is a member of the bond-core pub workspace, so the `bond_*` packages
resolve to the local sources. From this directory:

```sh
fvm flutter pub get
fvm flutter run
fvm flutter test
```
